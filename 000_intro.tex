\section*{Введение}
\thispagestyle{withCompileDate}

Существуют два принципиально разных подхода к организации работы с данными в \db{} \todo{(расшифровка)}: \oltp{} (Online Transaction Processing, интерактивная транзакционная обработка) и \olap{} (Online Analytical Processing, интерактивная аналитическая обработка).

\postgresql{} \todo{ссылки}~--- реляционная \dbms{} с открытым исходным кодом, в основе которой лежат принципы \oltp{} \todo{(переформулировать)}.

В последнее время \todo{наблюдается тенденция по объединению \oltp{} и \olap{} подходов в \postgresql{} для создания единой платформы по работе с данными} \cite{postgresproOlapOltpPdfTalk}.

В данной работе будут рассмотрены существующие технологии для \olap{}-обработки данных в \postgresql{} с использованием формата данных \parquet{} и проведен сравнительный анализ производительности различных подходов выполнения \olap{}-запросов в \postgresql{}.
