\section{Тестирование и апробация}
    В данном разделе будут кратко описаны процессы тестирования приложения и проведения апробации среди пользователей, а также их результаты.

    \subsection{Тестирование}
        Backend API приложения покрыт юнит-тестами с использованием \pytest{}. Процент покрытия составляет 91\% операторов (см. Рис. \ref{fig:testcov}).

        \begin{figure}[h!]
            \centering
            \includegraphics[width=0.9\textwidth]{figures/test_coverage.png}
            \caption{Результат запуска тестов}
            \label{fig:testcov}
        \end{figure}


    \subsection{Апробация}
        Апробация проводилась среди пользователей приложения по методике \systemusabilityscale{} (\sus{}) \cite{brooke1996sus}.

        Опрос состоял из 10 стандартных для методики вопросов, адаптированных под разработанное приложение.

        \todov{На данный момент} в опросе приняли участие \todov{два пользователя}.

        Результирующая оценка считалась по формуле, приведенной в \cite{lewis2018system}, и получилась равной 71.25.
