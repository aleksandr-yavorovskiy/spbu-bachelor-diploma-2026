Тестовый стенд:
\begin{itemize}
    \item HUAWEI MateBook D15 BoDE-WXX9
    \item CPU: 11th Gen Intel(R) Core(TM) i5-1155G7 @ 2.50GHz
    \item Ядра: 8
    \item Зафиксированная частота процессора: 4000 GHz
    \item ОЗУ: 16GB
    \item ОС: Ubuntu 22.04.4 LTS
    \item \postgresql{} 18.1 (Ubuntu 18.1-1.pgdg22.04+2)
\end{itemize}
