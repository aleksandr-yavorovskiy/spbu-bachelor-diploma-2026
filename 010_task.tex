\section{Постановка задачи}
\label{sec:task}

Целью работы является разработка приложения для работы с оцифрованными кириллическими рукописями. Для её выполнения были постав\-лены следующие задачи:
\begin{enumerate}
    \item собрать и проработать требования к инструменту;
    \item провести обзор шрифтов, используемых при наборе кириллических текстов, с целью определения лучшего по количеству верно отображаемых символов и выявления особенностей отображения для каждого из шрифтов;
    \item спроектировать архитектуру приложения;
    \item реализовать разработанное решение;
    \item развернуть приложение на сервере;
    \item провести апробацию инструмента среди пользователей;
    \item обеспечить тестовое покрытие кода backend API приложения не менее 70\% операторов (statements).
\end{enumerate}
